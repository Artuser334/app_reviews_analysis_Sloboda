Курсова робота з дисципліни **«Мови програмування для аналізу даних»**

## Опис проєкту

Програмний проєкт для очищення, статистичного аналізу та візуалізації відгуків користувачів **Google Play Store** засобами Python, Pandas, Matplotlib і Seaborn. У роботі досліджується зв’язок метаданих застосунків (категорія, рейтинг, ціна, кількість встановлень) з тональністю (sentiment) відгуків, групові відмінності Free/Paid, часові показники оновлень. Підсумкові агрегати готуються для інтерактивного аналізу; публікація панелі в Tableau Public не виконувалась — дані та опис структури дашборда збережені в `tableau/`.

**Мета:** розвинути відтворюваний цикл EDA на реальному наборі даних і сформувати обґрунтовані висновки щодо якості досвіду користувачів мобільних застосунків.

**Дослідницькі питання:**

1. Як розподіляється настрій відгуків і які категорії мають найнижчу середню полярність?
2. Чи пов’язані `Rating` та `Sentiment_Polarity` / `Sentiment_Subjectivity`?
3. Чим відрізняються настрій і полярність для безплатних (Free) і платних (Paid) застосунків?
4. Які категорії — лідери та аутсайдери за кількістю відгуків і середньою оцінкою?
5. Як змінюються часові показники (`Year_Last_Update`) за обсягом і середньою полярністю?

## Набір даних

| Файл | Опис |
|------|------|
| `data/raw/googleplaystore.csv` | Метадані застосунків (категорія, рейтинг, ціна, installs, дата оновлення) |

## Основні результати (після очищення та join)

- **28 250** відгуків · **816** застосунків · **33** категорії  
- Настрій: Positive **64,2 %**, Negative **21,4 %**, Neutral **14,3 %**  
- Середня полярність ≈ **0,19**; Free ≈ 0,19, Paid ≈ 0,22  
- Найнижча середня полярність: **GAME**, **SOCIAL**, **FAMILY**  
- Кореляція `Rating` ↔ `Sentiment_Polarity` ≈ **0,11** (слабка позитивна; ≠ причинність)

## Відтворюваність
